# Riya Gupta — resume portfolio

A responsive, single-page Next.js App Router portfolio based on the supplied resume, with the original portrait, downloadable PDF, career history, initiatives, skills, education, and direct contact links.

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3001.

## Production

```sh
npm run build
```

The site is configured for static export. Deploy the generated `out/` directory to a static host, or deploy the project using a Next.js-compatible provider. Edit portfolio content in `app/page.tsx` and styles in `app/globals.css`. The provided assets are stored in `public/`.
